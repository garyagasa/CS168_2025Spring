# CS168_2025Spring

Berkeley [CS 168 Spring 2025](https://sp25.cs168.io/)（Computer Networks）的项目、课件、discussion 和考试资料。

## 项目

课程网站标注的测试版本：Project 1 用 Python 3.11，Project 2 用 Python 3.8，Project 3 用 Python 3.7（POX 声明支持 Python 3.6–3.10）。

| 项目 | 目录 | 主要文件 |
| --- | --- | --- |
| Project 1: Traceroute | `projects/proj1-traceroute` | `traceroute.py` |
| Project 2: Distance-Vector Routing | `projects/proj2-routing` | `simulator/dv_router.py` |
| Project 3: Transport | `projects/proj3-transport` | `ext/cs168p2/student_socket.py` |

## 课程资料

- `Slides/Lectures/`：Lecture 01–27，共 25 份 PDF。Lecture 5–6、14–15、19–20 共用课件，Lecture 23 分成两部分。
- `Slides/Discussions/`：Discussion 01、04 的原始 PPTX。
- `discussions/`：Discussion 01–12 的题目和官方解答。
- `exams/`：Spring 2025 期中、期末试题和官方解答，以及 Reference Card。
- `CS168_Notes.pdf`：整理过的笔记。
- `Notes/`：前两讲的中文笔记（`lecture-01`、`lecture-02`）。
- `Readings/`：`reading1.pdf`、`reading2.pdf`、`reading3.pdf`。

课件、讨论和试卷的版权属于课程教师。
